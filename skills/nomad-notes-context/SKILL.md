# nomad-notes-context

## Purpose

Read a constrained, read-only Apple Notes snapshot and turn it into context candidates for Nomad Life.

This Skill is intentionally narrow. It should start with a dedicated folder such as `Nomad Life` and should not read the user's entire Notes database.

## Input Data

- Note title
- Creation date
- Modification date
- Optional short body preview
- Folder name
- Account name

## Read Locations

```txt
data/context/notes-context.json
data/action_logs/YYYY-MM-DD.jsonl
```

The context file is generated by:

```bash
scripts/read_notes_context.py --folder "Nomad Life"
```

Or through the daily runner:

```bash
scripts/run_nomad_daily.py --include-local-apps
```

## Available Tools

- Local files
- Terminal script
- AppleScript bridge to Notes
- Hermes read-only review

## Procedure

1. Read `data/context/notes-context.json`.
2. Check `scope.folder` and confirm the read scope is constrained.
3. Check `data_quality.status`.
4. If status is `empty`, report that the folder is connected but currently has no usable notes.
5. If notes exist, treat them as context candidates, not facts.
6. Map title-based note signals to likely downstream Skills such as work, creator, travel, rest, or quick capture.
7. Ask Coordinator to decide whether any note should become a capture, draft, or action suggestion.

## Output Shape

Notes context should be consumed as:

```json
{
  "agent_name": "nomad-notes-context",
  "status": "empty | partial | unavailable",
  "note_count": 0,
  "scope": {
    "folder": "Nomad Life"
  },
  "candidate_agents": [],
  "signals": [],
  "recommendations": []
}
```

## Do Not

- Do not read all Apple Notes by default.
- Do not write, move, delete, or edit notes.
- Do not treat note titles or previews as final user intent.
- Do not surface sensitive note details unless they directly support the user's requested review.
- Do not enable full note body ingestion without explicit scope review.

## Example

If a note titled `Bali cafe work ideas` appears:

```txt
이 노트는 작업 장소/콘텐츠 소재 후보로 보입니다. 아직 실행 액션이 아니라 Creator 또는 Work Agent가 참고할 context candidate로 유지합니다.
```
