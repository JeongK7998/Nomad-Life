Rules

Do — keep clearspace ≥ symbol height

The symbol's height defines the minimum padding around any logo. No element — type, image, or container edge — enters this zone.

Do — use the three approved colors

Black (#171719), white, and Wanted Blue (#0066FF) only. The mark may sit on a photographic background only when contrast exceeds 4.5 : 1.

Don't — gradient, outline, or rotate

The mark is a single solid colour. No gradients, drop-shadows, outlines, rotations, or stretching.

Don't — recolour the wordmark

If you need a tinted logo for a marketing surface, use the symbol on a tinted background — never recolour the wordmark itself.
